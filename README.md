## Flooding-Client-V2

통합 학교 관리 시스템

| 커밋 타입   | 의미                        | 릴리즈 노트 섹션 |
| ----------- | --------------------------- | ---------------- |
| `feat:`     | 새로운 기능 추가            | ✨ 새로운 기능   |
| `change:`   | 기능 수정                   | 🔄 기능 수정     |
| `refactor:` | 코드 리팩토링               | ♻️ 리팩토링      |
| `fix:`      | 버그 수정                   | 🐛 버그 수정     |
| `remove:`   | 삭제                        | 🗑️ 삭제          |
| `docs:`     | 문서 수정                   | 📝 문서          |
| `chore:`    | 빌드, 패키지 매니저 설정 등 | 🔧 기타          |
